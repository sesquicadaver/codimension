# Архів: codimension.org

Статичне дзеркало сайту [codimension.org](http://codimension.org) (оригінальний upstream, ~2017–2020).

**Не оновлюється.** Інструкції тут можуть бути застарілими:

- `pip install codimension` — PyPI-версія upstream, не [форк sesquicadaver](https://github.com/sesquicadaver/codimension)
- Python 2, cdmpyparser/cdmcfparser як обов’язкові залежності
- Посилання на неактивні репозиторії

Актуальна документація форку: [doc/README.md](../README.md).

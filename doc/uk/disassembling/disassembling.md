Аналіз: дизасемблювання
=======================

Codimension підтримує дизасемблювання коду Python. Результат дизасемблювання може
відрізнятися залежно від рівня оптимізації:

- без оптимізації
- рівень оптимізації 1
- рівень оптимізації 2

Є кілька способів запустити аналіз:

- Обрати пункт головного меню `Tools -> Disassembly`, а потім потрібний
  рівень оптимізації для дизасемблювання
- Натиснути кнопку на вертикальній панелі інструментів вкладки з маленькою іконкою молотка
- Скористатися контекстним меню для файла Python у проєкті або у
  браузері файлової системи та обрати пункт `Disassembly`, а потім потрібний
  рівень оптимізації.

Кнопка на вертикальній панелі інструментів вкладки за замовчуванням запускає
дизасемблювання без оптимізації.

![Дизасемблювання для вкладки](../disassembling/disasmtab.png "Дизасемблювання для вкладки")

Кнопка підтримує розкривне меню: якщо натиснути на неї й утримувати
кнопку миші приблизно секунду, з’явиться меню з додатковими параметрами.

![Меню кнопки дизасемблювання](../disassembling/disasmbuttonmenu.png "Меню кнопки дизасемблювання")

Незалежно від способу запуску аналізу результати будуть показані
однаково. Codimension відкриє іншу вкладку з результатами дизасемблювання:

![Результати дизасемблювання](../disassembling/disasmresult.png "Результати дизасемблювання")

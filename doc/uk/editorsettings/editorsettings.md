Налаштування IDE
================

Codimension підтримує низку параметрів, які можна налаштувати через редагування
файлів скінів. Див. документацію [тут](../../colorschemes/colorschemes.md).

Крім того, Codimension має інтерфейс для зміни деяких найчастіше
використовуваних параметрів, включно з налаштуваннями редактора. Інтерфейс доступний у
головному меню IDE -> Options

![Параметри IDE](../editorsettings/options.png "Параметри IDE")

Усі параметри, які можна обрати, представлені перемикачами або прапорцями. Вибір будь-якого з них
(окрім скіну) одразу впливає на IDE.

| Параметр | Опис |
|:---------|:-----|
| Show vertical edge | Показувати вертикальну межу в текстовому редакторі на певному символі. За замовчуванням: 80. Можна змінити через редагування `~/.codimension3/settings.json` |
| Show whitespaces | Показувати символи пробілів у текстовому редакторі, якщо між словами не рівно один символ |
| Wrap long lines | Якщо рядок не вміщується в доступну ширину, він переноситься на наступний (лише відображення) |
| Show brace matching | Підсвічувати дужки, коли текстовий курсор на одній із них |
| Show indentation guides | Показувати направляючі відступів (лише якщо символи пробілів приховані) |
| Highlight current line | Підсвічувати рядок, де знаходиться курсор |
| HOME to first non space | Переміщувати текстовий курсор на перший символ, що не є пробілом, при натисканні клавіші HOME |
| Auto remove trailing spaces on save | Автоматично видаляти пробіли в кінці рядка під час збереження файла |
| Editor calltips | Показувати calltips редактора |
| Show navigation bar | Показувати панель навігації текстового редактора |
| Show control flow navigation bar | Показувати панель навігації потоку керування |
| Show main toolbar | Показувати головну панель інструментів |
| Redirected I/O | Підменю для вибору поведінки вкладки перенаправленого I/O внизу |
| Tooltips | Підменю для вибору підказок, які відображатиме IDE |
| Open tabs button | Підменю для вказання поведінки IDE, коли натиснуто кнопку 'Open tabs' і обрано елемент |
| Skins | Підменю для вибору скіну IDE (потрібен перезапуск IDE) |
| Styles | Підменю для вибору зовнішнього вигляду віджетів бібліотеки QT |
| Text mono font family | Підменю для вибору моноширинного шрифту |
| Editor margin font family | Підменю для вибору шрифту поля редактора |
| Flow mono font family | Підменю для вибору шрифту графічної панелі |
| Flow badge font family | Підменю для вибору шрифту значків елементів області видимості на графічній панелі |

Підменю для вибору шрифтів заповнюються динамічно залежно від того, які шрифти
доступні на конкретній системі. У Linux користувачі можуть додати шрифти,
щоб вони були доступні в Codimension, скопіювавши файли шрифтів у
каталог `~/.fonts`. Ось кілька посилань на шрифти, які можуть бути
цікавими:

- моноширинний шрифт [Iosevka](https://github.com/be5invis/Iosevka)
- моноширинний шрифт [Ubuntu](http://font.ubuntu.com/) mono
- моноширинний шрифт [Cascadia](https://github.com/microsoft/cascadia-code)

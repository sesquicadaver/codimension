# CML — Codimension Markup Language

CML — мікромова розмітки, яка використовує Python-коментарі для зберігання
додаткової інформації, що застосовується під час генерації графічного
представлення коду.

Кожен CML-коментар складається з одного або кількох суміжних рядків. Формат
першого рядка:

```python
# cml <version> <type> [key=value pairs]
```

Формат наступних рядків (за потреби):

```python
# cml+ <продовження попереднього рядка CML>
```

Літерали `cml` і `cml+` відрізняють CML-коментар від усіх інших
коментарів. Поле version — ціле число, введене для майбутніх
розширень при еволюції CML. type визначає, що саме буде зроблено при
малюванні діаграми. type — рядковий ідентифікатор, наприклад `rt` (replace
text — заміна тексту). Пари key=value дозволяють мати довільну кількість аргументів
для CML-коментарів.

## CML v.1

### Пари ключ — значення

Ключі мають бути коректними ідентифікаторами.

Значення — довільні рядки. Якщо значення містить пробіли — воно має бути
в подвійних лапках; інакше лапки необов'язкові. Символ подвійної лапки всередині
значення екранується зворотним слешем.

### Кольори

Деякі CML-коментарі підтримують специфікацію кольорів, наприклад для
фону графічного примітиву. Значення кольору можна вказати одним із
способів:

| Формат          | Опис                 |
| :-------------: | -------------------- |
| #hhh            | шістнадцятковий RGB  |
| #hhhh           | шістнадцятковий RGBA |
| #hhhhhh         | шістнадцятковий RRGGBB |
| #hhhhhhhh       | шістнадцятковий RRGGBBAA |
| ddd,ddd,ddd     | десятковий RGB       |
| ddd,ddd,ddd,ddd | десятковий RGBA      |

### cc

Коментар `cc` використовується для власних кольорів більшості графічних елементів.

Підтримувані властивості:

| Властивість | Опис                                    |
| :------: | --------------------------------------- |
| bg       | колір фону елемента, необов'язково      |
| fg       | колір переднього плану, необов'язково     |
| border   | колір рамки, необов'язково              |

Приклад:

```python
# cml 1 cc bg=#f6f4e4 fg=#000 border=#fff
```

### gb

Коментар `gb` позначає початок візуальної групи.
Потрібна парна CML-директива `ge`, що позначає кінець візуальної
групи.

Підтримувані властивості:

| Властивість | Опис                                                  |
| :------: | ------------------------------------------------------- |
| id       | унікальний ідентифікатор візуальної групи, обов'язково |
| title    | заголовок при згорнутій групі, необов'язково            |
| bg       | колір фону, необов'язково                               |
| fg       | колір переднього плану, необов'язково                   |
| border   | колір рамки, необов'язково                              |

Приклад:

```python
# cml 1 gb id="1234-5678-444444" title="MD5 calculation"
```

### ge

Коментар `ge` позначає кінець візуальної групи. Потрібна парна
CML-директива `gb`, що позначає початок групи.

Підтримувані властивості:

| Властивість | Опис                                           |
| :------: | ------------------------------------------------ |
| id       | унікальний ідентифікатор візуальної групи, обов'язково |

Приклад:

```python
# cml 1 ge id="1234-5678-444444"
```

### rt

Коментар `rt` замінює текст більшості графічних елементів.

Підтримувані властивості:

| Властивість | Опис                                              |
| :------: | ---------------------------------------------------- |
| text     | текст для відображення замість реального коду, обов'язково |

Приклад:

```python
# cml 1 rt text="Reset the dictionary"
```

### sw

Коментар `sw` для операторів `if` і `elif` перемикає розташування гілки
«Ні» за замовчуванням — на праву сторону.

Підтримувані властивості: немає

Приклад:

```python
# cml 1 sw
```

### doc

Коментар `doc` використовується для посилань на документацію.
Може з'являтися як:

- незалежний коментар
- leading-коментар
- trailing-коментар

У side-коментарях не розпізнається.

Підтримувані властивості:

| Властивість | Опис                                          |
| :------: | ---------------------------------------------------- |
| link     | посилання на документацію, необов'язково |
| anchor   | id якоря для посилання на цю точку коду з документації або іншого doc-коментаря, необов'язково |
| title    | текст на діаграмі, необов'язково (якщо не вказано — показується `doc`) |
| bg       | колір фону, необов'язково                             |
| fg       | колір переднього плану, необов'язково                 |
| border   | колір рамки, необов'язково                              |

Потрібно вказати принаймні link або anchor.

Посилання підтримує формати:

- http://... — викликається зовнішній браузер
- https://... — викликається зовнішній браузер
- [file:]absolute path[#anchorOrLine]
- [file:]relative path[#anchorOrLine]. Відносний шлях перевіряється відносно поточного файлу, потім кореня проєкту

Якір має відповідати правилу: [_a-zA-Z0-9]+

Приклад:

```python
# cml 1 doc link="http://codimension.org"
```

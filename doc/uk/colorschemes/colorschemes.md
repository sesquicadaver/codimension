Кольорові схеми Codimension
=============================

Вступ
-----

Codimension використовує skins (теми) для визначення вигляду елементів
інтерфейсу. Skin — набір файлів у призначеному каталозі:

- app.css: таблиця стилів застосунку
- skin.json: загальні налаштування
- cflow.json: налаштування діаграми потоку керування

app.css відповідає
[специфікації CSS застосунку QT](https://doc.qt.io/qt-5/stylesheet.html).

Файли skin.json і cflow.json використовують формат JSON. Це словники
для зберігання різних налаштувань. Ключі в словниках — рядки з
урахуванням регістру.

При старті Codimension шукає доступні skins у

```
~/.codimension3/skins/
```

Codimension очікує, що для кожного skin є каталог з зазначеними вище
файлами.

При першому запуску Codimension створює каталог `~/.codimension3/skins/sample`
і заповнює необхідні файли значеннями за замовчуванням. Каталог sample
служить відправною точкою для створення власного skin. Каталог sample не
аналізується при побудові списку доступних skins.

Створення нового skin
---------------------

Один із варіантів:

- створити новий каталог, наприклад `~/.codimension3/skins/myskin`
- скопіювати skin.json, cflow.json і app.css з
  `~/.codimension3/skins/sample` у `~/.codimension3/skins/myskin`
- відкрити `~/.codimension3/skins/myskin/skin.json` і оновити значення "name",
  наприклад "My new skin". Наступного разу при старті Codimension у головному
  меню з'явиться `Options -> Themes -> My new skin`. Якщо обрати цей пункт,
  Codimension використовуватиме налаштування з нового каталогу.

Тепер значення у файлах skin можна безпечно змінювати. Після змін
потрібен перезапуск IDE, оскільки файли читаються лише при старті.

Формати кольорів і шрифтів
--------------------------

skin.json і cflow.json дозволяють налаштувати шрифти та кольори для багатьох
елементів. Формат кольору — рядок з чотирма значеннями через кому від 0 до 255:
червоний, зелений, синій і alpha. Приклад: "208,208,208,255"

Формат шрифту — рядок, який QT повертає як
[QFont.toString()](https://doc.qt.io/qt-5/qfont.html#toString).
Приклад: "Iosevka Term SS01,12,-1,5,50,0,0,0,0,0"

cflow.json
----------

Файл містить налаштування потоку керування — кольори окремих
графічних елементів, шрифти, відступи тощо. Назви ключів зроблені
інтуїтивними; детального опису немає — експериментуйте, щоб побачити
вплив на графічне представлення.

app.css
-------

Файл містить налаштування стандартних віджетів QT: QToolTip,
QLineEdit тощо. Документація доступна
[тут](https://doc.qt.io/qt-5/stylesheet.html).

Включення нового skin у пакет
-----------------------------

Якщо skin потрібно включити в дистрибутив для всіх користувачів:

- каталог skin додається до `codimension/skins/` проєкту
- враховуються платформні особливості (наприклад, доступність шрифтів)
- коригується setup.py проєкту

Іноді налаштування мають бути платформно-специфічними. Наприклад, на двох
платформах доступні різні моноширинні шрифти. Codimension використовує
суфікси імен файлів для платформи:

```
<ім'я файлу> + '.' + sys.platform.lower()
```

При старті, копіюючи skins з пакета в домашній каталог, Codimension
спочатку шукає платформно-специфічний файл. Якщо знайдено — копіює з
обрізаним суфіксом.

Перевизначення окремих значень skin
-----------------------------------

Окремі значення skin можна перевизначити. Для цього покладіть json-файл
override.json зі словником у каталог skin, значення якого потрібно змінити.
Значення з цього файлу оновлять словник skin.

Каталог skin може містити pixmaps (png і svg), які матимуть пріоритет
при завантаженні pixmap у Codimension.

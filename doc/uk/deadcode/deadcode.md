Аналіз: мертвий код
===================

Codimension інтегрує пакет Python Vulture
([репозиторій на GitHub](https://github.com/jendrikseipp/vulture))
для пошуку невикористаного коду в окремих файлах Python, а також у всьому проєкті.

Щоб запустити аналіз для окремого файла Python, його потрібно відкрити в
редакторі. Потім можна скористатися одним із двох способів:

- Обрати пункт головного меню `Tools -> Find tab dead code`
- Натиснути кнопку на вертикальній панелі інструментів вкладки з маленькою іконкою труни

![Vulture для вкладки](../../deadcode/vulturetab.png "Vulture для вкладки")

Аналіз може тривати певний час залежно від розміру файла, тому з’являється
модальне вікно прогресу, яке зникне одразу після завершення аналізу.

Результати з’являться на вкладці `Search results` внизу.

![Результати Vulture](../../deadcode/vultureresult.png "Результати Vulture")

Аналіз носить рекомендаційний характер, тому результати слід уважно перевірити
перед тим, як щось видаляти.

Якщо завантажено проєкт, аналіз мертвого коду можна запустити для всіх
файлів Python у проєкті одразу. Для цього також є два способи:

- Обрати пункт головного меню `Tools -> Find project dead code`
- Натиснути кнопку на горизонтальній панелі інструментів IDE з маленькою іконкою труни

![Vulture для проєкту](../../deadcode/vultureprj.png "Vulture для проєкту")

Аналогічно з’явиться модальне вікно прогресу, а результати будуть доступні
на вкладці `Search results` внизу.

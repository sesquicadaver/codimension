Аналіз: залежності
==================

Codimension підтримує побудову діаграм імпортів для файла Python,
для каталогу з файлами Python і для всього проєкту. У Python оператори
import задають залежності, тому саме вони враховуються під час
побудови цих діаграм.

Строго кажучи, можуть існувати також залежності від даних. Наприклад, вихідний код
може відкривати файли даних або сокети і читати з них. Такі залежності на
згенерованій діаграмі не показуються (принаймні на момент написання цього тексту).

Щоб запустити побудову діаграм імпортів, підтримуються кілька варіантів. Для окремого файла:

- Натиснути кнопку на вертикальній панелі інструментів, коли завантажено файл Python
- Натиснути кнопку на вертикальній панелі інструментів, коли завантажено файл Python,
  і утримувати її миттю. З’явиться контекстне меню з
  параметром детально налаштованої діаграми імпортів. Оберіть цей пункт.
- Обрати пункт головного меню `Diagrams -> Tab imports diagram`, коли завантажено файл Python
- Обрати пункт головного меню `Diagrams -> Tab imports diagram...`, коли завантажено
  файл Python. Цей пункт призначений для детально налаштованої діаграми імпортів.

Ось як виглядає кнопка на панелі інструментів: див. верхній правий кут. На кнопці
іконка з’єднаних блоків.

![Панель інструментів](../../dependencies/importtoolbar.png "Кнопка панелі інструментів для побудови діаграми імпортів")

Якщо обрано параметр детально налаштованої діаграми, з’явиться таке вікно:

![Діалог налаштування діаграми імпортів](../../dependencies/fineimportsdiagramdialog.png "Діалог налаштування діаграми імпортів")

Є кілька параметрів того, що включати до згенерованої діаграми.

Щоб запустити побудову діаграми імпортів для групи файлів,
скористайтеся:

- Усі файли в каталозі: відкрийте контекстне меню для каталогу в оглядачі
  проєкту. Оберіть пункт `Imports diagram` або `Fine tuned imports diagram`.
- Усі файли проєкту: натисніть кнопку на головній панелі інструментів (іконка з’єднаних блоків)
- Усі файли проєкту: натисніть кнопку на головній панелі інструментів (іконка з’єднаних блоків)
  і утримуйте її миттю. З’явиться контекстне меню з
  параметром детально налаштованої діаграми імпортів. Оберіть цей пункт.
- Усі файли проєкту: оберіть пункт головного меню `Diagrams -> Project imports diagram`.
- Усі файли проєкту: оберіть пункт головного меню `Diagrams -> Project imports diagram...`.

**Примітка:** Шляхи в *Exclude from analysis* (властивості проєкту) та venv
проєкту виключаються з набору файлів проєкту. Див. [Проєкт](../../project/project.md).

Згенерована діаграма імпортів виглядає приблизно так:

![Діаграма імпортів](../../dependencies/importsdiagram.png "Діаграма імпортів")

Діаграма має кольорове кодування. Різні кольори використовуються для

- модулів (файлів), які аналізувалися на залежності
- стандартних модулів
- модулів, шляхи до яких не вдалося визначити
- інших модулів проєкту
- інших модулів поза проєктом

На діаграмі також підтримується певна інтерактивність. Docstring модулів
показуються як підказки для іконок у верхньому правому куті. Подвійне натискання на
модулі відкриває відповідний файл, якщо це можливо. Аналогічно подвійне натискання на
імпортованому елементі також відкриває файл.
